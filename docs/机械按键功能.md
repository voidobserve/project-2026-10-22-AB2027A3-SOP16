# 机械按键功能

机械按键检测在 `user_app/io_key`：

```text
key_driver_scan(&io_scan_param)
  → io_key_apply()
  → io_key1_click_handle()
  → led_app_mechanical_next()
```

只处理 **CLICK**，不做长按。机械模式与 2.4G 模式相互独立。

## 2. 索引状态机

索引 `0~19` 只保存在 RAM，不写 NVM。

```text
上电 / 第一次机械键
  → 索引 0（W254）

开灯状态按机械键
  → 索引 +1

索引 18 再按
  → 索引 19
  → 关灯
  → 下一次开灯回索引 0

索引 19 时按机械键
  → 索引 0
  → 开灯 W254
```

为了满足“第一次机械键先显示白光 0”，使用 RAM 标志：

```c
led_app_mechanical_used_flag
```

- 上电为 0；
- 第一次机械键落索引 0，并置 1；
- 之后每次机械键索引 +1；
- 2.4G 切模式不清零该标志/索引；
- 掉电重新上电，索引和标志都回 0。

### 关灯后的开灯

| 场景 | 结果 |
|---|---|
| 机械模式 19 关灯后按机械键 | 索引 0，W254 |
| 机械模式 19 关灯后按 R1C1 | 索引 0，W254 |
| R1C1 关灯后按机械键 | 索引 0，W254 |
| R1C1 关灯后按 R1C1 | 恢复关灯前的模式/机械索引 |
| Modes H 关灯后按机械键 | 索引 0，W254 |
| 断电前机械索引 5，重新上电 | 机械模式，索引 0，W254 |

## 3. 亮度

| 机械索引 | 是否乘全局亮度 |
|---:|---|
| 0~2 | 否，固定 W254/W149/W49 |
| 3 Fade | 否，100% |
| 4~11 静态单色 | 是 |
| 12~17 静态图案 | 是 |
| 18 高变化 | 否，100% |
| 19 关灯 | 不输出 |

这样：

- 机械 0/1/2 始终是 W254/W149/W49；
- 机械 4~17 跟随远程 Dimming；
- Fade/高变化固定 100%。

---

## 4. 与 2.4G 模式的关系

- 机械索引独立于 2.4G 的 Fade/Strobe/Modes/静态色；
- 2.4G 切走时，不清零机械索引；
- 下次机械键从上次机械索引继续 +1；
- 机械键切回机械模式时，以新的机械索引为准；
- 机械关灯会清 Timer；
- Timer 激活时按机械键，Timer 继续，提示结束后回当前机械模式；
- 机械关灯则 Timer 立即取消，不再回机械模式。

## 5. NVM

保存：

- `mode = MECHANICAL`；
- power。

不保存：

- 机械索引；
- `led_app_mechanical_used_flag`；
- Timer。

上电如果保存的是机械模式：

- 索引 0；
- 白光 W254；
- 亮度 100%；
- Timer 无效。

机械索引 5 时断电，重新上电也是机械白光 0。

## 6. 高变化模式 18

高变化是按原始采集最后几轮做的逐灯表，不是简单彩虹。

### 6.1 颜色轮

```text
0 绿   (0,254,0)
1 青   (0,127,127)
2 蓝   (0,0,254)
3 粉红 (199,9,49)
4 红   (254,0,0)
5 橙   (203,50,0)
6 暖白 (127,127,0)
```

### 6.2 12 灯颜色偏移

```text
0, 1, 3, 4, 5, 0, 1, 3, 4, 5, 2, 3
```

### 6.3 12 灯时间偏移

```text
0, 3, 48, 93, 138, 182, 267, 353, 397, 483, 651, 696 ms
```

### 6.4 波次

- 每约 1537 ms 推进一个波次；
- 7 个波次一轮；
- 每盏灯用“时间偏移 + 颜色偏移”查表；
- 输出固定 100%，不乘全局亮度。

实现位置：

- `led_animation.c` 的 `mechanical_high_change_colors`
- `mechanical_high_change_color_offset`
- `mechanical_high_change_time_offset_ms`
- `mechanical_high_change_get_lamp_color()`
