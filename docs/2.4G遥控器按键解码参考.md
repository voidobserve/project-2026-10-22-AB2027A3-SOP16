
`project/example` 下面虽然没有单独的"2.4G 解码"示例（那里的解码例程只有 IR 红外 NEC 硬件解码），但 SDK 提供了完整的 **2.4G 私有协议收发接口**和**接收端解码参考例程**，位置如下：

## 1. 解码/收数接口（底层 API）

`api_wireless.h` 就是你要的"解码接口"入口，核心是数据接收回调：

```c
typedef void (* wireless_receive_callback_t)(uint16_t con_handle, uint8_t *packet, uint8_t size);

void wireless_receive_handler_register(wireless_receive_callback_t handler);  // 注册收数回调（解码入口）
void wireless_event_handler_register(wireless_event_callback_t handler);      // 连接/断开/广播事件
int  wireless_send_for_con(uint16_t con_handle, uint8_t *buf, uint16_t size); // 发送
int  wireless_rxbuf_release(uint8_t *buffer);                                 // 用完必须释放 rxbuf
```

协议栈以库形式提供：`libs/wireless/` 下的 `libwireless_master.a`（接收器/主机端）、`libwireless_slave.a`（遥控器/从机端）。

## 2. 2.4G 遥控器解码例程（接收端 dongle）

最完整的参考是 `wireless_remote_dongle` 方案（2.4G 遥控器 USB 接收器），`wireless_client.c:174` 里的 `wireless_receive_handler()` 演示了典型的"收包→按类型解析→分发"解码流程：

```c
if (packet[0] == WIRELESS_PACKET_TYPE_HID) {                       // 0x01 键盘/鼠标报告
    usb_usr_hid_keyboard_write((hid_rep_keyboard_t *)&packet[2]);
}
if (packet[0] == WIRELESS_PACKET_TYPE_AUDIO && ...) {              // 0x02 语音数据
    usb_usr_audio_mic_write(&packet[2], packet[1]);
}
wireless_rxbuf_release(packet);
```

包类型定义在 `wireless.h:15`（HID=0x01 / AUDIO=0x02 / CTRL=0x04）。

## 3. 配对的两端基础参考

- `wireless_central`：主机/接收端，含扫描、按 RSSI 连接、多连接管理、rxbuf 队列处理（`wireless_client.c:188`）
- `wireless_peripheral`：从机/遥控器端，含广播、连接后 `wireless_send_for_con()` 发数（`wireless_service.c:48`）

## 说明

- 如果你说的"解码"是指**接收自家 2.4G 遥控器的数据并解析按键/语音**：上面的 `wireless_remote_dongle` 就是现成例程，接口即 `wireless_receive_handler_register()`。
- 如果是指**解码第三方/非配对 2.4G 遥控器的射频协议**（类似红外 NEC 解码那种）：SDK 没有这类例程。2.4G 协议栈是闭源库，只能在配对链路内收发原始包，无法做物理层/链路层裸包解码；硬件解码能力只提供给 IR（`driver_irrx.c`，仅 NEC，参考 `example/IR/main.c`）。

需要的话，我可以照 `example/IR` 的风格帮你写一个精简的 2.4G 收包解码示例（注册回调 + 自定义包格式解析）。
